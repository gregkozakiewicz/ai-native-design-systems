# Wheels

One folder per bounded question, numbered in the order they were started.
Create one with `tools/new-wheel.sh "name"`. See the root `README.md` for
what a wheel has to contain.

| # | Question | Status |
| --- | --- | --- |
| [001](001-button-variant/) | Can an agent choose the correct button variant from machine-readable rules alone? | answered: yes, 87 of 87 with rules against 63 of 87 with prose (run 3) |
| [002](002-other-models/) | Does the rule set guide models other than Opus 5.5? | answered: yes, 9 models from 4 companies all score 80 to 87 of 87 with rules; 3 open readings found |
| [003](003-three-missing-rules/) | Do the 3 sentences from wheel 002 close its misses? | answered: no, misses rose from 32 to 40; 2 decisions for the designer |
