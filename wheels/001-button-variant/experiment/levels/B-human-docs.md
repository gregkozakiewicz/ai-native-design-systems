# Button

Buttons let people take actions. Choose the variant that matches how important the action is.

## Variants

### Primary

Use primary for the main action on a page or in a dialog, the thing most people came to do. It has a filled background and the strongest visual weight.

Examples: "Save", "Continue", "Create account".

### Secondary

Use secondary for actions that are important but not the main one. It has a border and a neutral background.

Examples: "Cancel", "Export", "Edit".

### Ghost

Use ghost for low-emphasis actions, or where a button needs to sit quietly in a busy area such as a toolbar, card or table. It has no border or background until hovered.

Examples: "Learn more", "Skip", "View details".

### Destructive

Use destructive for actions that delete data or can't be undone. It uses the error colour so people slow down before clicking.

Examples: "Delete", "Remove".

## Guidelines

- Keep the number of primary buttons low so the main action stands out.
- Pair a destructive button with a way to back out, such as "Cancel".
- Use clear, action-led labels like "Save changes" rather than "OK".

If none of the variants fits, answer "none".
