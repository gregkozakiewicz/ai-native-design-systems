# 003: three missing rules

**Status:** answered: no, misses rose from 32 to 40; one sentence worked, two did not
**Started:** 8 October 2026

## Question

Do the 3 sentences proposed by wheel 002 close the 32 misses in the button variant rules without opening new ones, on the same 10 models?

## Why it matters

Wheel 002 showed the 12 rules had the same impact across companies, and that every miss came from 3 readings the rules leave open. The method says a rule enters the system only when a run proves it. If the 3 sentences work, the button rule set is finished and can be written into `system/` as proved on 10 models. If they do not, that is worth knowing before the same approach is tried on bigger decisions.

## Boundary

**In scope**

- the 29 scenarios and correct answers from wheel 001, unchanged
- the 10 models from wheel 002, at the same settings, including Fable 5.1 at low effort
- level C only: the rule file from wheel 001 plus the 3 sentences, and nothing else changed
- 3 repeats per scenario per model, 870 answers

**Out of scope**

- levels A and B; they are unchanged from wheel 002 and would score the same
- any other change to the rules, however tempting
- new scenarios; the 3 sentences are judged on the 29 that found the gaps

## Success criteria

- answered "closed" if every model scores 87 of 87, or if the only remaining misses are on scenarios that were not among wheel 002's 6 splits (a new gap, to be named)
- answered "partly" if misses fall but any of the 6 split scenarios still splits across models
- answered "no" if the total misses do not fall below 32, or if a sentence opens a new split on a scenario that was unanimous before
- abandon if a model cannot be run at the same setting as in wheel 002
